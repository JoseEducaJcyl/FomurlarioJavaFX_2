# FormularioJavaFX_2

Proyecto desarrollado en Java utilizando JavaFX y Maven para practicar la creación de formularios y la gestión de interfaces gráficas de usuario.

## Descripción

La aplicación implementa un formulario gráfico mediante JavaFX, utilizando diferentes controles visuales para la entrada e interacción de datos por parte del usuario.

Este proyecto sirve como práctica para trabajar con componentes gráficos, organización de elementos y manejo básico de eventos en aplicaciones de escritorio Java.

## Tecnologías utilizadas

- Java
- JavaFX
- Maven

## Requisitos

- JDK 17 o superior
- Maven instalado
- IDE compatible con JavaFX
